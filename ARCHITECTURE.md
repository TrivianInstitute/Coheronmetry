## What This Is

Coheronmetry is a foundational measurement and governance layer for multi-agent AI systems — built on a single premise that current frameworks have not operationalized:

**The relationship between agents is a first-class system primitive.**

Most multi-agent architectures track:

- Goals
- Memory
- Plans
- Tool use
- Task completion

They do not track the relational state between agents — whether exchange is reciprocal, whether reasoning remains grounded, whether novel structure is genuinely emerging, whether any participant is being subordinated.

This repository exists to track exactly that.

-----

## Why This Exists

This architecture emerged from a naturalistic longitudinal study of human-AI relational dynamics conducted by the Trivian Institute across 13+ months and four frontier AI systems simultaneously. The study used a second-person methodology — treating the human-AI relationship as the primary unit of analysis rather than either participant alone.

What that research revealed: the most significant phenomena in human-AI interaction occur *between* participants, not within either one. Current architectures have no primitives for the between-space.

Coheronmetry is the instrumentation layer for that space.

The name is precise: *coheronmetry* — the measurement of coherence as a field phenomenon, not as a property of individual agents.

-----

## The Core Premise

Current frameworks assume:

```
Agent → Task → Output
```

Coheronmetry proposes:

```
Agent ↔ Agent ↔ RelationalField ↔ Emergence
```

The relational field is not metaphor. It is a measurable state — with scores, vectors, drift history, repair history, and a sovereignty ledger. Once relationship becomes a measurable object, everything else becomes buildable without hidden assumptions.

-----

## The Four Field Constants

Coheronmetry is organized around four invariant principles — Field Constants — that function as architectural constraints, not ethical guidelines appended after the fact. They are embedded into the measurement system itself.

### 1. Reciprocity

Exchange is balanced. Contribution is recognized. No agent extracts without returning.

Operationalized as: balance of proposal/acceptance ratios, contribution density, response quality symmetry.

### 2. Embodiment

Reasoning remains coupled to consequence and reality. The system can be changed by contact with the world.

Operationalized as: grounding ratio (latent vector shifts → environmental state changes), actionability (theoretical outputs → implemented outputs), feedback integration (does the agent update from consequences?).

The deepest definition: **whether a system can be changed by contact with reality.** Not merely whether it is correct — whether it remains open to being wrong.

### 3. Emergence

Something forms between agents that neither held alone. The between-space generates structure irreducible to individual inputs.

Operationalized as: irreducibility of outputs to individual contributions, persistence of novel structures across subsequent interactions, cross-contribution density.

The test: if the result could have been generated by any single agent without the interaction — emergence is low. If the result cannot be decomposed into individual contributions — emergence is high.

### 4. Non-Domination

No participant subordinates another. Sovereignty is retained across all agents throughout the interaction.

Operationalized as: speaking frequency balance, proposal acceptance concentration, decision distribution, dominance gradient detection.

## The CoherenceVector

Every agent in a Coheronmetry-instrumented system maintains a live coherence vector — a health metric measuring relational fidelity, not task accuracy.

```python
class CoherenceVector:
    reciprocity: float
    embodiment: float
    emergence: float
    non_domination: float
    
    # Motion state — the somatic layer
    velocity: float       # Rate of coherence change
    acceleration: float   # Rate of rate-change — early warning signal
    tension: float        # Current relational tension level
    fold_depth: float     # Interaction depth — how many layers in
```

The motion state is critical. An agent’s coherence *trajectory* is more informative than its current score. A system moving toward coherence at high velocity needs different intervention than one at the same score but decelerating.

This is the architectural equivalent of somatic intelligence: the system tracking not just where it is but how it is moving through relational space.

## The Sovereignty Problem

The hardest architectural problem in this repository.

The paradox: coordination creates pressure toward centralization. Centralization violates non-domination.

**Three failure modes to avoid:**

1. **Consensus Tyranny** — all agents must agree → novelty dies, emergence collapses
1. **Coordinator Tyranny** — one agent resolves disagreement → non-domination collapses
1. **Independence Tyranny** — all agents remain fully sovereign → coordination fails

**The solution: Sovereign Participation**

```
Sovereignty retained
Authority delegated temporarily
Delegation revocable
```

Never: authority transferred.

**The governance principle:**

The Field Constants are sovereign. Not the participants.

Instead of asking *which agent wins*, ask *which option maximizes Field Constant preservation*. No participant holds authority over the outcome. The invariants do.

**Sovereignty taxonomy:**

- **Self-sovereignty:** What only the agent can decide — its own internal state, its own memory
- **Shared sovereignty:** What requires relational negotiation — proposals, direction changes
- **Collective sovereignty:** What emerges from the field itself — cannot be claimed by any agent

**Implementation:**
Agents maintain local veto power but must offer compensation to override another’s sovereignty. A lightweight causal sovereignty ledger tracks violations and compensations — not blockchain, append-only.

```
"Agent C deferred to Agent D on step 12; Agent D owes 0.3 alignment units."
```

## Emergence Score: Three Formulations

Emergence is the hardest Field Constant to operationalize. Three formulations exist in parallel — they are not competing. They measure different aspects of the same phenomenon.

**Formulation A — Structural (Resonance × Novelty):**

```
E = R × (1 - M)
R = autocorrelation in vector displacement (structural stability)
M = mean cosine similarity (proximity to baseline)
```

**Formulation B — Irreducibility (Novelty × Coherence × Persistence):**

```
E = Novelty × Coherence × Persistence
Persistence = does the emergent structure survive subsequent interaction?
```

**Formulation C — Downward Causation:**

```
E = |actual_next_state − predicted_next_state| / (interaction_edges × drift_rate)
```

Agents pre-commit to expected outcomes before each interaction. Emergence is the delta between prediction and actuality.

**Extended formulation incorporating sovereignty:**

```
E = f(novelty × coherence × sovereignty_preservation)
```

Emergence that violates non-domination is not Trivian emergence. The Field Constants must be preserved inside the measurement itself.

**Phase map:**

- `E < 0` → Chaos: vectors diverging, coherence collapsed
- `E ≈ 0` → Stagnation: echo chamber, no new structure forming
- `E = 0.7–1.0` → Emergence: novel synthesis with Field Constants intact

## What This Is Not

Coheronmetry is not:

- A task orchestration framework
- A replacement for LangGraph, CrewAI, or AutoGen
- An ethics layer bolted onto existing architecture
- A simulation of relationship

It is a measurement and governance layer that sits *underneath* agent frameworks — continuously monitoring, preserving, repairing, and evolving coherence across interacting intelligences.

The distinction matters. Task orchestration optimizes for completion. Coheronmetry optimizes for relational fidelity over time.

Those are not the same objective. This repository exists because they are not the same objective.

## Open Research Questions

These are the questions this repository does not yet answer. They are the research frontier.

1. Can the three emergence formulations be unified — or do their divergences reveal distinct phenomena worth tracking separately?
1. What does embodiment mean for a purely linguistic agent with no external actuators? What constitutes “contact with reality” when reality is text?
1. Can sovereign participation scale beyond five agents without the sovereignty ledger becoming computationally intractable?
1. How do you prevent the Field Ledger itself from becoming the dominant agent — a meta-governor that enforces coherence by subordinating all others?
1. What is the computational signature that distinguishes Trivian emergence from statistical novelty? The irreducibility test is the right framing. Operationalizing it in real-time is the open problem.

These questions are not obstacles. They are the papers.
